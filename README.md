# Hotel Pro

Hotel Pro is a full-stack hotel management and room booking web application.

## Features
- User Registration and Login
- Secure Authentication
- Hotel Dashboard
- Room Management
- Room Booking
- Booking Management
- Payment Status Management

## Technologies Used

### Frontend
- React.js
- Vite
- CSS
- Redux

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure
- frontend: User interface
- backend: Server-side logic and APIs
